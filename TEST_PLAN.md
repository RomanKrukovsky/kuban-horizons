# TEST_PLAN.md — план тестирования Kuban Horizons

## 1. Уровни тестирования

1. **Компиляция и сборка**: `./gradlew clean build` — на каждый коммит (CI).
2. **Datagen-чистота**: `./gradlew runData` + `git status --porcelain
   src/generated` пуст — сгенерированное соответствует коду.
3. **GameTest**: `./gradlew runGameTestServer` — полный автоматический
   прогон на каждый PR.
4. **Ручные smoke-прогоны** (перед релизом): клиент, новый мир, старый мир,
   dedicated server, 2 игрока, перезаход, перезапуск сервера.

## 3. Релизный чек-лист (10 этап)

1. `./gradlew clean build` — успех.
2. `runData` — без диффа.
3. Запуск клиента, создание нового мира, 10 минут игры.
4. Загрузка мира предыдущей версии мода — без потерь.
5. Запуск dedicated server (eula), подключение клиента.
6. Два клиента одновременно; совместная работа с одним устройством.
7. Выход/вход, перезапуск сервера — состояние сохранено.
8. Полный GameTest — зелёный.
9. `latest.log` клиента и сервера: нет ERROR, нет новых WARN от мода.
10. Проверка лицензий (THIRD_PARTY_NOTICES.md актуален).

## 4. Регрессии

Любой найденный баг получает: issue → GameTest, воспроизводящий баг →
исправление → тест остаётся в наборе.
