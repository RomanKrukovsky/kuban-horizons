# Kuban Horizons / Кубанские горизонты

> От чернозёмной степи до Чёрного моря.

**Kuban Horizons** — крупный survival- и exploration-мод для Minecraft Java
Edition (NeoForge), переносящий в игру собирательный образ Кубани:
чернозёмные степи, поля подсолнечника, рисовые чеки, плавни и лиманы,
виноградники, предгорья Кавказа, Азовское и Черноморское побережья,
чайные плантации, станицы, фермы, винодельни и пасеки.

Это не географический симулятор и не политическая реконструкция. Мод
передаёт природу, хозяйство, архитектуру, кухню и атмосферу региона
уважительно, без карикатур и стереотипов.

## Возможности (в разработке)

- 🌻 Региональные культуры: подсолнечник, виноград, рис, кукуруза, чай,
  арбуз, томат, плодовые деревья.
- 🌱 Система плодородия почвы: чернозём, истощение, компост, севооборот.
- 💧 Орошение: каналы, желоба, шлюзы, водозаборы.
- ⚙️ Переработка: маслопресс, мельница, сушилка, виноградный пресс,
  коптильня, сыроварня и другие устройства.
- 🍲 Региональная кухня: борщ, вареники, пирожки, мамалыга и др.
- 🌍 Новые биомы: степь, плавни, лиманы, виноградные холмы, горные леса,
  побережья, влажные субтропики.
- 🏘️ Структуры: станицы, хутора, курени, пасеки, винодельни, рынки,
  мельницы, рыбацкие посёлки, дольмены.
- 🐗 Животные: фазан, нутрия, кабан, кавказская пчела, осетровые, чайки, цапли.
- 🤝 Региональные профессии поселенцев и торговля.
- 🏗️ Архитектурные наборы: белёная штукатурка, саман, ракушечник,
  черепица, плетень, резные наличники.
- 📖 Внутриигровое руководство «Путеводитель по Кубани».
- 🏆 Дерево достижений.
- 🖥️ Полная поддержка dedicated server.

## Требования

| Компонент | Версия |
|-----------|--------|
| Minecraft Java Edition | 26.2 |
| NeoForge | 26.2.0.48-beta или новее в линейке 26.2 |
| Java (для игры) | 25 (поставляется с лаунчером) |

## Установка

1. Установите NeoForge для Minecraft 26.2.
2. Поместите `kubanhorizons-<версия>.jar` в папку `mods`.
3. Запустите игру. Для сервера — положите JAR в `mods` сервера.

## Сборка из исходников

```bash
./gradlew build
```

Готовый JAR: `build/libs/kubanhorizons-<версия>.jar`.

Другие полезные команды:

```bash
./gradlew runClient          # запуск клиента
./gradlew runServer          # запуск dedicated server
./gradlew runData            # генерация данных (datagen)
./gradlew runGameTestServer  # полный прогон GameTest
```

## Внешний разум джиннии

Сервер может подключить диалоговый слой Кубанской джиннии к модели
`euromodels/gpt-5.6-sol` через OpenAI-совместимый EuroModels API. Ключ никогда
не хранится в мире, конфиге или JAR: перед запуском сервера задайте переменную
окружения `EUROMODELS_API_KEY`.

После привязки джиннии используйте `/genie <сообщение>`. HTTP-запрос выполняется
асинхронно и не блокирует игровой тик. Модель может разговаривать и учитывать
переданный контекст отношений, но не может выполнять команды или напрямую
менять мир: все эффекты проходят через локальные валидаторы мода. Без сети или
ключа продолжает работать локальный предиктивный `GenieBrain`.
